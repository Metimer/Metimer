## About

I build AI systems that move from notebook experiments to production workflows.

My work sits at the intersection of **data engineering**, **applied machine learning**, and **LLM applications**. I care about systems that are measurable, reliable, and useful beyond a demo.

Currently focused on:

- retrieval quality and RAG architecture
- agentic workflows with tool use
- evaluation loops for LLM systems
- data pipelines that support real products

## Focus Areas

| Area | Practical Work |

| **Machine Learning** | model training, evaluation, feature design, experimentation |
| **LLM Systems** | RAG, agents, context design, observability, cost control |
| **BI & Analytics** | dashboards, semantic layers, decision-support interfaces |
